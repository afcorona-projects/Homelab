# Homelab Docs

Documentation for a Proxmox home lab, kept up to date every night by Jarvis, a self-hosted AI assistant. Each machine's page, the network and its routes, storage, backups, a changelog and incident write-ups (built from Loki) are generated from the live lab.

**Read it here:** https://afcorona-projects.github.io/Homelab/

This repo is the public copy. The private one lives on a Forgejo server at home; before each push, LAN addresses are swapped for machine names, the home domain becomes example.com, private notes are left out, and a secret scan (gitleaks) has to come back clean.

Built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/).
